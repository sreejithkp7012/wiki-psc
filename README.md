# WiKi PSC

മലയാളത്തിൽ Kerala PSC പഠനത്തിനായി തയ്യാറാക്കിയ ഒരു simple, responsive study website.

## Features
- 12 PSC subjects
- Completed subjects checklist
- Automatic progress percentage
- Progress saved in browser localStorage
- Dark / Light mode
- Mobile responsive design

## Files
- `index.html` — main page
- `style.css` — design
- `script.js` — checklist, progress & theme logic
